# Integrações

## Gmail

O coletor usa IMAP com uma senha de aplicativo e abre a caixa de entrada em modo
somente leitura. Credenciais nunca devem ser armazenadas neste repositório.

## Telegram

O bot utiliza um token privado e restringe comandos a um identificador de chat
autorizado. Novas vagas entram numa fila persistente de entrega.

## Instagram

A integração requer uma conta profissional, aplicativo no Meta for Developers,
permissões de publicação e uma URL HTTPS pública para as imagens.

## LinkedIn

Os dados chegam por alertas enviados ao e-mail do usuário. O projeto não automatiza
login nem realiza scraping do site.
